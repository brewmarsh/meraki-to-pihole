🚨 Severity: HIGH
💡 Vulnerability: The API endpoints (`/update-meraki`, `/update-pihole`) accepted state-changing `POST` requests without any form of Cross-Site Request Forgery (CSRF) protection.
🎯 Impact: A malicious webpage visited by an authorized user on the local network could trigger hidden form submissions against the dashboard, executing unauthorized syncs and potentially causing a Denial of Service.
🔧 Fix: Implemented `CSRFMiddleware` that requires the `X-Requested-With: XMLHttpRequest` custom header on all state-changing HTTP methods. Updated the frontend `fetch` calls and test suites to include the header.
✅ Verification: Ran `poetry run pytest` to ensure all endpoints function securely.
