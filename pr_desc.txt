💡 What: Added pre-filtering of devices by `meraki_network_ids` before executing the `ThreadPoolExecutor` to fetch fixed IP assignments in `app/clients/meraki_client.py`.
🎯 Why: To prevent the N+1 external API call problem. When fetching devices from the Meraki organization, the ThreadPoolExecutor was making an individual HTTP request for every device to get its fixed IP assignments, even if the device was not in the target networks.
📊 Impact: Reduces total Meraki API requests significantly. O(N) filtering reduces total API requests by the number of excluded devices, preventing rate limiting and lowering execution latency.
🔬 Measurement: O(N) local filtering of the `devices` list instead of O(N) external HTTP requests.
