💡 What: Added a "Skip to main content" link to the application layout templates (`index.html`, `404.html`, `500.html`, `docs.html`).
🎯 Why: To allow keyboard-only and screen reader users to bypass repetitive navigation elements (like the navbar) and jump directly to the primary page content, improving overall usability.
📸 Before/After: The link is visually hidden until focused via the keyboard using Bootstrap's `visually-hidden-focusable` class. The main content wrappers were appropriately converted from generic `<div>` tags to semantic `<main>` tags.
♿ Accessibility: Ensures WCAG compliance for bypassing blocks (Success Criterion 2.4.1), with proper `tabindex="-1"` and `outline: none` to support clean programmatic focus shifting.
