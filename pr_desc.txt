🚨 Severity: HIGH
💡 Vulnerability: The FastAPI endpoints that perform state-changing actions (`/update-meraki`, `/update-pihole`, `/update-interval`, `/clear-log`) lacked Cross-Site Request Forgery (CSRF) protection.
🎯 Impact: An attacker could construct malicious requests on external sites to trigger unauthorized actions on behalf of an authenticated user interacting with the app.
🔧 Fix: Added a `CSRFProtectionMiddleware` that enforces an `X-Requested-With: XMLHttpRequest` header on all non-GET/HEAD/OPTIONS/TRACE API requests. Modified the frontend HTML template and the test suite to include this custom header in all `POST` requests.
✅ Verification: Ran the full automated test suite to ensure the new middleware integrates seamlessly and the requests are validated appropriately.
