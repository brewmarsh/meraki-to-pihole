💡 What: Added a visually-hidden 'Skip to main content' link targeting the main container.
🎯 Why: Improves accessibility for keyboard and screen reader users by allowing them to skip repetitive navigation links and jump straight to the content.
📸 Before/After: Visuals verified (screenshot provided).
♿ Accessibility: The target main container was updated from a `div` to a semantic `<main>` tag, received a `tabindex="-1"` so it can be programmatically focused, and an `outline: none;` style to avoid an unsightly focus ring on the entire layout when accessed.
