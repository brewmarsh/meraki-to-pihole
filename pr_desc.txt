💡 What: Added a 'Skip to main content' link to both `index.html` and `docs.html` that becomes visible on keyboard focus and skips over navigation straight to the main `<main>` container.

🎯 Why: Users relying on keyboards or screen readers often have to tab through repetitive navigation links on every single page load before reaching the actual content they care about. This provides a fast, standard bypass mechanism.

📸 Before/After: Before, keyboard users had to tab through the navbar on every page. After, the first tab stop on the page is a visually hidden skip link that jumps focus directly to the main content area (which was converted from a `<div>` to a semantically correct `<main>` tag with `tabindex="-1"` and `outline: none;`).

♿ Accessibility: Directly addresses WCAG 2.1 Success Criterion 2.4.1 (Bypass Blocks) by providing a mechanism to bypass blocks of content that are repeated on multiple Web pages. Used Bootstrap's `visually-hidden-focusable` class to ensure it's invisible to mouse users but accessible to keyboard users. Changed main wrapper to `<main>` tag. Added Bootstrap CSS to docs page to support the utility class.
