💡 What: Added a "Skip to main content" link at the very top of the document body using Bootstrap's `visually-hidden-focusable` class. The link targets a new semantically correct `<main>` container which replaced the generic `<div class="container">`. The target is focusable without a visible outline using `tabindex="-1"` and `style="outline: none;"`

🎯 Why: To improve accessibility for keyboard and screen reader users by providing them with a fast way to bypass repetitive navigation elements and directly access the main content of the dashboard.

📸 Before/After: Visual changes only appear on tab focus. The skip link appears dynamically, and focus correctly shifts into the main layout container.

♿ Accessibility: Implements WCAG guideline 2.4.1 (Bypass Blocks), adds a semantic `<main>` tag, and improves programmatic focus management without compromising visual aesthetics.
