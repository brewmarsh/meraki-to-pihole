💡 What: Added a "Skip to main content" link at the top of the index page and changed the main content wrapper to a semantic `<main>` tag.
🎯 Why: To allow keyboard-only and screen-reader users to bypass the navigation header and jump directly to the primary application content.
📸 Before/After: Before, keyboard users had to tab through the navigation menu on every visit. After, the first tab stop is the skip link, saving time and effort.
♿ Accessibility: Improves WCAG 2.4.1 (Bypass Blocks) compliance. Implemented using Bootstrap's `.visually-hidden-focusable` so it is invisible until focused, and applied `outline: none;` to the target container to prevent a jarring focus ring when programmatic focus is shifted.
