💡 What: Added a "Skip to main content" link hidden off-screen that becomes visible when focused, and changed the primary content container to a `<main>` tag with `tabindex="-1"` and `style="outline: none;"`.
🎯 Why: Keyboard and screen reader users need a way to bypass repetitive navigation elements (like the navbar) to jump directly to the primary content of the page.
📸 Before/After: Before, keyboard users had to tab through the navigation elements every time the page loaded. After, they can tab once to focus the "Skip to main content" link and press Enter to jump to the charts and data.
♿ Accessibility: Addresses the missing "skip-to-content links" issue and improves semantic HTML by using a proper `<main>` container for the core application layout.
