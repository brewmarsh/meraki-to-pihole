💡 What: Added a "Skip to main content" link to the top of the page.
🎯 Why: To allow keyboard and screen reader users to quickly bypass repetitive navigation links (like the welcome banner and navbar) and jump directly to the core content.
📸 Before/After: Before, keyboard users had to tab through the welcome modal (if present), the brand link, and the dark mode switch before reaching the main charts and cards. After, the very first tab stop is a hidden link that, when activated, immediately moves focus to the main content container.
♿ Accessibility: Improves navigation for keyboard-only users. Uses Bootstrap's `visually-hidden-focusable` to keep the link hidden for mouse users until it receives keyboard focus. Changed the main `div` container to a semantic `<main>` tag, added `tabindex="-1"` so it can receive programmatic focus, and added `style="outline: none;"` to prevent an unsightly focus ring on the entire container when jumped to.
